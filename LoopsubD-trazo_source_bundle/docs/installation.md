# Installation / Instalação

## Português

1. Baixe o ZIP da versão publicada na página **Releases** do repositório.
2. Abra o IngeTrazo e acesse o Gerenciador de Extensões.
3. Escolha a instalação a partir de arquivo e selecione o ZIP.
4. Reinicie o aplicativo se for solicitado.
5. Localize LoopsubD no gerenciador/painel de extensões.

Se estiver atualizando uma versão anterior, mantenha uma cópia de segurança dos seus arquivos de projeto. Faça a primeira validação em um arquivo de teste.

## English

1. Download the release ZIP from the repository's **Releases** page.
2. Open IngeTrazo and go to the Extension Manager.
3. Choose installation from a file and select the ZIP.
4. Restart the application if prompted.
5. Find LoopsubD in the extension manager/panel.

When upgrading, keep backups of your project files and validate the new version in a test document first.
